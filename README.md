# CP Problem Tracker
A console coursework project built in C# to track competitive programming progress.


## Features
- Log solved problems with name and link
- Track your daily solving streak
- View total problems solved and last 30 days stats
- JSON-based persistence across sessions

## How to Run
Make sure you have [.NET SDK](https://dotnet.microsoft.com/download) installed, then:

```bash
dotnet run
```

## Tech
- C# / .NET
- `System.Text.Json` for data persistence
- OOP design with interfaces and encapsulation
